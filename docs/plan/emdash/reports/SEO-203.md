# SEO-203 (GON-203): SEO-panel overrides and article metadata

Branch `emdash/SEO-203` (from `feat/emdash` 0c21899d).

## What changed
- `apps/web/src/lib/seo.ts` (new): `loadSeoByContentId("posts")` reads every `_emdash_seo` row of the collection in ONE query (`getDb()` from `emdash/runtime`, memoised), keyed by `entry.data.id` (the ULID). `resolvePostSeo()` resolves title, description, image, canonical and noindex through EmDash's `getSeoMeta()`. `getEmDashCollection()` does not fold `_emdash_seo` (only `getEmDashEntry()` does, via `foldedSeoSelect`), and `<EmDashHead>`'s `peekSeoPanel` overlay is SSR-only, so a batched query is the cheap build-time equivalent (996 `getEmDashEntry` calls avoided).
- `lib/content.ts`: `BlogPost` gains `dbId` (ULID), `seo`, `publishedAt`, `updatedAt`, `author`; `getAllPosts()` attaches `seo`.
- `[slug].astro` -> `BlogPost.astro` -> `Global.astro`: pass resolved `title`, `pageTitle`, `description`, `image`, `canonical`, `noindex`. `content` is now `{ collection: "posts", id: dbUlid, slug }`. Posts use `pageType="article"` with `articleMeta` (`publishedTime` = legacy date, `modifiedTime` = CMS `updatedAt`, `author` = byline, else `SITE_AUTHOR` "Gong"; there are no bylines in the DB).
- Title format: default stays the legacy `GrowGen | 给我整 | <title>` (also og:title/twitter:title, as in legacy). A panel title replaces the whole string.
- Robots: `BaseHead.astro` no longer emits `<meta name="robots">`. `Global` passes page-level `noindex` (404, /cv) and per-entry `noIndex` as `page.seo.robots`, so `<EmDashHead>` is the only emitter and dedupes against its staging tag (first wins). This fixes the 404 that showed `noindex,follow` plus `noindex, nofollow`.
- Pre-cutover noindex is untouched: it is the `_headers` X-Robots-Tag, `robots.txt` and the INF-10 `PUBLIC_SITE_LIVE` gate in `post-build.mjs`. Per-entry `noIndex=false` emits nothing, so it can never lift it.
- Sitemap: `scripts/seo/write-noindex.ts` (pre-build, read-only transaction) writes `apps/web/.astro/seo-noindex.json` (gitignored; always rewritten); the `@astrojs/sitemap` `filter` in `astro.config.mjs` drops those posts (`scripts/seo/noindex-list.mjs`). `build` script runs it before `astro build`.
- Guard: `scripts/post-build.mjs` now fails the build if any built HTML has more than one `<meta name="robots">`.

## Notes and follow-ups
- `modifiedTime` is the CMS `updated_at`, which for imported posts is the import time (Nov 2026), not an editorial edit. Consider using the legacy date until a post is edited in the admin.
- Not done (follow-ups): `seo` for podcasts (needs the same ULID join in `getAllPodcasts` and `podcast/[id].astro`); `_redirects` from `_emdash_redirects`.
