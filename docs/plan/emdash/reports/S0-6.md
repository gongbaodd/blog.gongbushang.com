# S0-6 report: publish -> rebuild plugin (D9)

**Verdict: PASS.** Live-tested locally against a fake GitHub listener.

## Plugin (`apps/web/src/plugins/rebuild-on-publish/`)
- Native plugin: `index.ts` (descriptor `{id, version, format:"native", entrypoint}` for `emdash({plugins:[...]})`), `plugin.ts` (exports `createPlugin` via `definePlugin`, `capabilities: ["content:read"]`, hook `content:afterPublish`), `dispatch.ts` (pure request builder and never-throwing sender).
- Hook signature (emdash 1.6.0 `types-YTpIfKXX.d.mts:1182`): `(event: {content: Record<string,unknown>, collection: string}, ctx: PluginContext) => Promise<void>`; `ctx.log` has info/warn/error. Native entry loading confirmed in `virtual-modules-DAvm-Tct.mjs` (`import { createPlugin } from entrypoint`).
- Sends `POST {GITHUB_API_URL||https://api.github.com}/repos/{GITHUB_DISPATCH_REPO}/dispatches`, `Authorization: Bearer ${GITHUB_DISPATCH_TOKEN}`, body `{event_type:"emdash-publish", client_payload:{collection,id,slug}}`. Repo var is validated (`owner/repo`, no `..`).
- Missing token or repo: logs and no-ops. Network error or non-204: logged, never thrown, token never logged.
- Env read from `cloudflare:workers` env, then `process.env`. Names added to `.dev.vars.example`.
