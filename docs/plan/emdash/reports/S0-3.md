## Failure modes (recorded)
| Condition | Result |
|---|---|
| env var set, DB up | OK |
| env var unset, `localConnectionString` in wrangler.jsonc | OK (wrangler falls back to the config value) |
| env var unset AND no `localConnectionString` (CI-like) | Build **fails**, exit 1: "When developing locally, you should use a local Postgres connection string ... set 'CLOUDFLARE_HYPERDRIVE_LOCAL_CONNECTION_STRING_HYPERDRIVE' or localConnectionString" |
| env var set but DB unreachable | **Silent**: build exits 0, logs `[emdash] runtime init failed (page renders without CMS data): connection attempt failed`, and emits an EMPTY list page (`<ul></ul>`) and no post pages |

The last row is dangerous for CI: a deploy could publish an empty site. Need a guard (build check that fails if the collection is empty or if the log contains "runtime init failed"); suggest Builder-Infra/Lead decide (a smoke-check step after build).
