# S0-4 report: Markdown body rendering (D5)

Branch `emdash/S0-4` (cut from `emdash/S0-3`). Verdict: **WORKS** (build-time only).

## Field
`apps/web/scripts/schema/add-body-md.sh` runs
`pnpm exec emdash schema add-field posts body_md --type text --label "Body (Markdown)" -u http://localhost:4322`.
The CLI has no options flag, so the `rows: 40` textarea option from the scout note cannot be set through it (set it in the admin or the seed).
Round trip: `emdash content create posts --slug md-spike --file post.json`, then `content get ... --json` returns `body_md` byte-for-byte identical (KaTeX, fences, attributes preserved).

## Implementation
- `apps/web/src/lib/markdown.ts`: `renderMarkdown(src) -> { html, headings }` using `createMarkdownProcessor()` (`@astrojs/markdown-remark` 7.3.1) with remark-attributes, remark-math, rehype-katex (strict false), rehype-external-links, rehypeCloudinary, Shiki (all `bundledLanguages` + shiki-plantuml, langAlias `{C:"c", plantuml:"PlantUML"}`).
- Cloudinary: **copied** to `apps/web/src/lib/cloudinary.ts` (not imported across the workspace boundary); noted in `apps/web/PORTING.md`.
- shiki-plantuml: `file:../../packages/shiki-plantuml` dependency (uses its built `dist`).
- Mermaid: `astro-mermaid` integration added to `astro.config.mjs` for the client script (conditional `import('mermaid')` only when `pre.mermaid` exists; emitted as `/_astro/page.*.js`, mermaid chunks in `dist/client/_astro`). Its remark plugin is internal, so `markdown.ts` has a 10-line `remarkMermaid` copy. It must run before Shiki: it is first in `remarkPlugins`.
- Page: `src/pages/spike/md/[slug].astro` (prerender, imports `katex/dist/katex.min.css`).

## Open points
- Shiki with all bundled languages makes the prerender build heavier; build time here was ~4s for 1 post, not measured at scale.
- KaTeX CSS must be imported by the layout that renders posts; mermaid client script is injected site-wide (tiny until a diagram exists).
- Admin editor is a plain textarea (no preview).
- Mermaid rendering in a browser was not run (client script is the unmodified astro-mermaid one).
