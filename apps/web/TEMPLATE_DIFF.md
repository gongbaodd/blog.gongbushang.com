Generated with: `pnpm create emdash@latest web --template cloudflare:starter --pm pnpm --no-install --yes`
(creator output: package `web@0.0.3`; installed `emdash@1.6.0`, `@emdash-cms/cloudflare@1.6.0`, `astro@7.4.13`, `@astrojs/cloudflare@14.4.9`).

## Unchanged but worth knowing

- `r2_buckets` (`MEDIA`) kept as generated for now; local dev uses Miniflare's local R2. Replaced by Cloudinary in S0-5/CMS-2.
- `durable_objects` (`EMDASH_ROOMS`, SQLite-backed), the `* * * * *` cron trigger, `images` (`IMAGES`) and `kv_namespaces` (`SESSION`) are auto-added by the template/adapter. Check each against the free tier before deploying (S0-4).
- The creator also writes `.agents/`, `.claude/`, `.cursor/`, `.vscode/`, `.mcp.json`, `AGENTS.md` into `apps/web`; kept untouched.
- `apps/web/.env` (holds `EMDASH_ENCRYPTION_KEY`) is generated by the creator and gitignored.

## Local database workflow

- `pnpm db:start` (root) starts only Postgres of the Supabase stack (`127.0.0.1:54322`, `postgres:postgres`); `db:stop`, `db:reset` likewise.
- Runtime (`pnpm --filter web dev`): migrations run automatically on first request through the Hyperdrive `localConnectionString`; the starter seed (`seed/seed.json`) is applied automatically too.
- `emdash migrate` CLI: `CLOUDFLARE_HYPERDRIVE_LOCAL_CONNECTION_STRING_HYPERDRIVE=<url> pnpm --filter web exec emdash migrate --from-config --status` (or `--check`; omit both to apply). The env var name is `migrationConnectionStringEnv`'s default for the `HYPERDRIVE` binding. `DATABASE_URL` is only for the plain `postgres()` adapter.
- `emdash init|seed|doctor|export-seed` are SQLite-only (`--database ./data.db`); they do not work against Postgres. Use the running instance instead: `emdash content create posts -u http://localhost:4322 --slug hello --data '{"title":"Hello"}'` (localhost dev bypass supplies the token).
- Wrangler quirk: the repo-root `wrangler.json` (legacy) confuses wrangler's generated-config redirect. In `apps/web` use `pnpm exec wrangler deploy --dry-run --outdir <dir> -c dist/server/wrangler.json`.
